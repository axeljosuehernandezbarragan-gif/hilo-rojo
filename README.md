# Hilo Rojo

Un juego narrativo para el navegador sobre seguridad digital y ciudadanía digital: eres Yare, de 17 años, y esta semana administras la página de bordados de tu abuela antes de la Feria del Bordado. Cada decisión deja un hilo que regresa días después.

Se juega en la computadora o en el celular, sin instalar nada. Hecho con HTML, CSS y JavaScript, sin frameworks; los dibujos son SVG hechos con código.

Reto 3 · Construye Aplicaciones Web · Escuela José María González Hermosillo.
Ambientes, pasos, teclado y lápiz: grabaciones de dominio público (CC0) de Freesound (créditos en `audio/CREDITOS.md`).
